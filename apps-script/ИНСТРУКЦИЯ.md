# Как подключить анкеты к боту (5 минут)

1. В Telegram открой @BotFather → `/newbot` → придумай имя. Скопируй токен.
2. Напиши своему новому боту `/start`.
3. Открой script.google.com → «Создать проект». Удали всё в редакторе и вставь код из `Code.gs`.
4. В первой строке вместо `ВСТАВЬ_ТОКЕН_БОТА` вставь токен. Сохрани (дискета).
5. Сверху выбери функцию `getChatId` → «Выполнить» → разреши доступ. Внизу в журнале появится `CHAT_ID = 123456789`. Вставь это число вместо `ВСТАВЬ_CHAT_ID`, сохрани.
6. Выбери `testMessage` → «Выполнить». В бот должна прийти тестовая анкета.
7. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение» → «У кого есть доступ: Все» → «Развернуть». Скопируй ссылку вида `https://script.google.com/macros/s/.../exec`.
8. Пришли эту ссылку Claude (или вставь в `anketa.js` в строку `var ENDPOINT = '';`).

Токен живёт только в твоём Google-аккаунте, на сайте его не видно.
Один и тот же скрипт работает для всех лендингов: бот сам пишет, с какого пришла анкета.
